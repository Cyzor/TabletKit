# emitToolCompatibility was made @_spi(TabletKitInternals) as part of the same
# Phase A pass that added this gate — deliberate, see the doc comment on the
# declaration in Core/DecoderModel.swift. Nothing outside the package called
# it, so this isn't a real break for any consumer.
API breakage: func emitToolCompatibility(toolCode:deviceFamily:state:results:) is now with @_spi

# XencelabsControl was renamed to XencelabsOutputProtocol, leaving a deprecated
# typealias behind for one cycle. The alias has now been removed, so relative to
# 0.3.0 the old enum name is gone. Still pre-1.0, and the only consumer is the
# app, which was updated in the same pass. The replacement type is a drop-in
# rename with an identical surface.
API breakage: enum XencelabsControl has been removed

# bpt3ContainersSincePen drove BPT3ContainerDecoder's pen-proximity gate, which
# was removed (see CHANGELOG "Fixed": the gate killed PTH-850 touch on a
# low-confidence pen hover). DecoderState is a decoder-internal state bag passed
# inout to decode(); nothing outside the package reads its fields. Pre-1.0,
# changelog-documented.
API breakage: var DecoderState.bpt3ContainersSincePen has been removed

# DigitizerSpec and WacomDeviceSpec both gained a `bezelButtonCount` field when

# initializers are synthesized and the added parameter changed both signatures.
# Pre-1.0, changelog-documented; the app is the only consumer and builds against
# the new shape. Callers that named every argument need the one new parameter.

# across the decode path and the tool catalog. Untyped "intuosProGen2"-style
